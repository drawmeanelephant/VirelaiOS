The image viewer — the `opens=image` default: QOI, PNG, JPEG,
GIF and SVG through the shared `webrender` decoder (deliberately
not a second decoder), MOV/Motion-JPEG through its bounded box
demux, zoom, pan, and animated playback with per-frame delays —
held to a still frame when `a11y.reduce_motion` is set. A missing
or undecodable file leaves the window open on a named state, the
old VIEW.BIN don't-panic rule. `live-image-viewer.spec` runs the
format spread in one boot; the tile is
[ICONVIEW](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/iconview.qoi).
