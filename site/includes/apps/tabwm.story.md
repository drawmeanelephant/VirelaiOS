The Zig tabbed desktop — the browser-style WM server that
retired floating windows for a tab strip and a sidebar (God Menu,
tab list, status tray), and the fleet's deliberate fallback seat:
ADR 0034 keeps it in the manifest while the Go seat owns the daily
default. Every catalog app is a first-class full tab inside it.
`live-tabwm.spec` drives its whole lifecycle on real hardware; the
tile is [ICONTABM](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/icontabm.qoi).
