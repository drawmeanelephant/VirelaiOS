Settings — the panel that edits the schema-v2 `SETTINGS.TXT`
the seat and kernel already read, every save a crash-safe publish.
Cycle a row's vocabulary with arrows or type `key=value` directly;
the services and access panes, the grants consent rows for signed
ReleaseCaps, the chord-registry shortcuts view and the font and
palette pickers all edit the same in-force table — unknown keys a
file carries survive a save byte-for-byte but are not offered for
editing. `go-settings.spec` toggles a row by real pointer press
and finds it persisted in the share. The tile is
[ICONSET](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/iconset.qoi).
