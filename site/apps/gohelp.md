The help browser — a Bubble Tea model over the bound tty that
walks the staged `/host/docs` bundle: group-jumps through the GOSH
command catalog, `/` filtering, full detail pages. Like GOFILES it
runs the model without the host Program loop — key bytes decode
from the bound `/dev/tty` queue and View's ANSI frames go back
into it. `go-help.spec` asserts a detail page's exact truecolour
accent in the real scanout, not a host ANSI render. The tile is
[ICONHELP](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/iconhelp.qoi).
