# Shell

The shell — exec, line editing, history, jobs/fg and the pipes /
redirection / env / variables scripting subset, running as a
full-viewport tabapp on the `/dev/tty` seam. One `shlib` engine
backs it and GOTERM alike; only the front-end owner changes —
the windowed tab, `GOSH.ELF serial` on the console the kernel
monitor hands over, or `GOSH.ELF net` with its challenge-response
handshake. `/host/STARTUP.SH` then `/host/PROFILE.SH` is the
startup contract, silent when missing. `go-sh.spec` reads the
scripted output back on the host byte-equal; the tile is
[ICONGOSH](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/icongosh.qoi), and the
[front-page shot](https://github.com/drawmeanelephant/VirelaiOS/blob/main/site/index.assets/gosh.png) is a real
session.
