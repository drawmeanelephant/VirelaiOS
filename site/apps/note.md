# Text Editor

The fleet's plain text editor — open, edit, `ctrl+s`, done. It is
deliberately not an editor arms race: GOEDIT owns that, while NOTE
stays the manifest's `opens=text` default and the seat specs'
canonical hosted tab. One shared muscle carries over anyway: Ctrl-F
docks the same appkit find overlay the reader uses, and a dirty
buffer autosaves on tab close so nothing typed is lost. Its whole
close-and-reopen journey — path and caret inside the appver-1
envelope — is what `go-note.spec` pins. The tile paints
[ICONNOTE](https://github.com/drawmeanelephant/VirelaiOS/blob/main/image/art/icons/iconnote.qoi), and the
[in-guest shot](https://github.com/drawmeanelephant/VirelaiOS/blob/main/site/index.assets/note.png) on the front page is
this window.
