# VirelaiOS — interface art

Delivered art for the [VirelaiOS](https://github.com/drawmeanelephant/VirelaiOS)
desktop: app icons, cursors, mascot poses, wallpapers, empty-state spots,
the brand plate, spinner frames, filetype icons.

Slugs carry their family prefix — `icon-`, `cursor-`, `mascot-`, `wallpaper-`,
`spot-`, `brand-`, `spinner-`, `filetype-`, `sheet-` — flat under this
directory (`art/virelai/<slug>/<slug>-V*R*.{vectorcraft,svg,@2x.png}`), so the
site scan sees every piece and alphabetical order groups the families.
