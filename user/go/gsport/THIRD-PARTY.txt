GOSTALGIA.ELF — third-party software notices
==============================================

The GOSTALGIA.ELF guest binary (M95, built by tools/go/build-gostalgia.sh
from the pinned Gostalgia tree at commit
7ef7d23502a85fb891f78fc92f223e2ba8994f46 plus this repository's local
overlays) statically links the following third-party Go modules. Their
sources are NOT vendored in this repository: they resolve into the host
Go module cache at build time and are overlaid, never copied in-tree.
This file carries the copyright and permission notices their licenses
require for binary redistribution.

Gostalgia itself is first-party owner code (owner decision 2026-10-05);
it carries no LICENSE file and needs none here. The `virelai` module
(user/go/, gsport) is this repository's own. The Go standard library is
BSD-3-Clause (Google), part of the toolchain, not a linked module.

Versions below match the module closure of `go list -deps ./cmd/gostalgia`
resolved against the staged modfile (.build/gostalgia.mod). The build
script fails if any module version linked into the ELF is absent from
this file; bumping a dependency requires re-resolving and updating it.
